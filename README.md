# Website

## Run Locally

**Prerequisite:** Node.js


1. Install dependencies with `npm install`.
2. Start the local development server with `npm run dev`.
3. Create a production build with `npm run build`.

The production site is written to `dist/`. Upload the contents of that folder to any static web host. The build uses relative asset paths, so it can also be served from a subdirectory. No API keys or platform-specific services are required.
